Carrier–Surface

A public, evidence-bounded transport contract for keeping identity, reconstruction, and provenance explicit while representations change.

Governing invariant

Object identity is invariant; coordinates are negotiable.

Smallest reusable core

Thing + Address + Relation + Carrier + Transform + Invariant + Provenance

Address

A multidimensional key or coordinate. One object may have several valid addresses.

Surface

An addressable relation or representation domain. A discrete multi-key relation is useful substrate; it is not automatically a mathematical manifold.

Carrier

A transport between Surfaces. It may change coordinates or representation while carrying declared invariants and provenance.

Preimage

Reverse lookup may return several addresses. Ambiguity remains explicit instead of being manufactured into a unique inverse.

Canonical traversal

RESOLVE → ENCODE → CARRY → DECODE → RECONSTRUCT → COMPARE → TRACE → RETURN_HOME

A failed invariant comparison is mutation, semantic decay, or unknown—not a successful semantic rotation.

Semantic rotation

A → Carrier → B → Carrier⁻¹ → A′

Compare A and A′ under the declared invariant set. Byte equality, semantic equivalence, and scientific truth remain distinct obligations.
