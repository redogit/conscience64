How the game treats failure

Crossing the event horizon or leaving the play area safely returns the probe to orbit. Scanned evidence and decision history are preserved. The design teaches by recovery rather than punishment.

Evidence ring

Scanning discovers a carrier. Admission is a separate human choice. Only admitted fragments are given to the optional LLM.

Conscience — AI proposal engine

Conscience works immediately through a deterministic local proposer. Its optional browser LLM is lazy-loaded only after you explicitly enable it; enabling it can download a local browser model.

Human Boundary Gate

Conscience cannot authorize itself. The separate Human Boundary Gate checks human benefit, agency, privacy, evidence, reversibility, cost, uncertainty, and hard boundaries.

Progressive fallback

  1. Core ECS, controls, evidence, and Conscience Gate load first.
  2. Renderer loads on demand: WebGPU → WebGL2 → Canvas 2D.
  3. LLM loads only on explicit request in a module worker; otherwise the deterministic proposer remains active.
  4. The text state remains usable even if advanced graphics fail.
