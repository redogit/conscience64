## What changed in the API

The unchanged 1.2.0 code was exercised locally through its actual Chromium postMessage bridge. `get(missing)` returned null, while `search.advanced({from:missing})` returned all 508 graph relations. Version 1.3.0 throws `UNRESOLVED_REFERENCE` for an unresolved supplied `from` or `to`, and `INVALID_REFERENCE` for malformed values. IRPO and bridge requests preserve those errors. This is not a measured zero.

The seven earlier project records, 734-object graph, transport shards and September 12 research files are unchanged. Lessons are a separate queryable registry layer; graph search does not silently search the lessons. The predecessor is commit `3f8889e17cecd7bd865e33f70201c703163df405` and remains in Git history.
