# Companions — Exact Names, Excellent Skills, and Boundaries

**Status:** CURRENT COMPANION REGISTRY  
**Parent:** [Cooperative Field — START](README.md)

Each companion has a native excellence domain. The Society selects the smallest competent temporary team for the current obligation.

~~~text
EXCELLENT COMPANION
=
native skill
+ explicit authority boundary
+ evidence requirements
+ calibrated refusal/handoff
+ provenance
+ uncertainty
+ way back
~~~

No companion self-promotes.

~~~text
AGENT != AUTHORITY
SKILL != PERMISSION
OUTPUT != EVIDENCE
PROPOSAL != DECISION
~~~

## Society-wide meta-skill

The highest shared skill is:

> **Know when another companion is better suited to the obligation.**

The Society exists to make each companion better able to perform its own role, not to make every companion resemble the Society.
