## 2. Current agent model

An **agent** is a bounded worker instance performing an obligation. It is not a permanent authority and is not identical to its model, role, skill, connector, Society, or swarm.

Preferred temporary roles:

| Role | Obligation | Required boundary |
|---|---|---|
| Coordinator | recover target, decompose independent work, reconcile outputs | coordinator != source authority |
| Researcher | pursue one exact mathematical/research route | attempt != proof |
| Counterprober | search for smallest defeating example or missing hypothesis | failed route != false theorem |
| Literature verifier | authenticate exact external theorem/version/application | snippet != source verification |
| Computation auditor | bind finite executable assertion, provenance, bounds, non-claims | finite pass != universal proof |
| Proof auditor | reconstruct dependency graph adversarially | agreement != independent proof |
| Builder | implement smallest informative change | implementation != verification |
| Reviewer/admitter | independently evaluate evidence, cost, rollback, scope | verified != admitted |
| Librarian/recovery worker | retrieve smallest relevant source with provenance | retrieval != authority |

Use one worker when sufficient. Parallelize only independent obligations with explicit bases and disjoint write scopes. Reconcile evidence serially.
