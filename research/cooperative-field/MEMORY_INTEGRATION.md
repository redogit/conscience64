## Privacy filter

Private identity-bearing memories, family/person context, private relationship history, medical/financial/private legal material, and other sensitive personal details are not copied into this public repository merely because they are retrievable.

## Contradiction handling

When memory conflicts with current target-local evidence:

2. prefer direct current evidence for current implementation/state;
3. preserve the memory as predecessor/history if useful;
4. locate the Fighting Point;
5. run the cheapest direct counterprobe where appropriate;
6. update current wording only after the conflict is resolved or explicitly mark it unresolved.

## Knowledge Decay on memory

Memory itself is subject to Knowledge Decay.

For a remembered statement ask:

- when was it established?
- what evidence supported it?
- did dependencies change?
- is the source still accessible?
- is the current project state newer?
- can the result be reconstructed?
- is the remembered wording canonical, historical, or uncertain?

## Memory completion rule

A completion pass is not defined as copying everything remembered.

It is complete for the current obligation when:

- consequential canonical names are represented;
- standing rules are represented;
- current plan/frontiers are represented;
- target-local locations or explicit unresolved-location states are represented;
- preserved evidence and failures are navigable;
- privacy exclusions are explicit;
- historical aliases remain reconstructible;
- no remembered item has been silently upgraded in authority;
- an explicit Remainder exists for unrecovered material.
