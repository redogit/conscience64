## Recoverable attribution and acceptance

`catalog.json.gz` carries every record's exact-content, statement, attribution, evidence/limits and source-link hashes, recorded dates, origin grade and source-reported status. The owner-held extended ledger and occurrence audit preserve the corresponding full source identities, original wording, raw attribution, chronology basis, windows and unresolved material. Private source identifiers, raw conversation history and image pixels are not published here. SHA-256 equality binds bytes; it establishes neither authorship nor truth.

The recovered acceptance artifact explicitly enumerates **895 source IDs** under the instruction “Mark all invariants as accepted research candidates.” The original 1,016-record catalog and the 72-record extension report inherited acceptance labels for the later **193** records. Both facts survive in the carrier: `source_reported_acceptance` retains the source label, while `acceptance_basis` distinguishes explicit ID coverage from inheritance without a separately recovered acceptance occurrence. Source attribution remains collaborative or unresolved where recorded; artifact dates are not invention dates. No historical acceptance event is fabricated.
