Carrier–Surface

Governing invariant:

Object identity is invariant; coordinates are negotiable.

Carrier–Surface is a small transport contract for moving the same identified thing between coordinate systems, schemas, representations, files, graphs, languages, decision fields, and other Surfaces without silently treating a representation change as an identity change.

Smallest reusable core

Thing + Address + Relation + Carrier + Transform + Invariant + Provenance

Address

A multidimensional key or coordinate. One object may have several valid addresses.

Surface

An addressable relation or representation domain. A discrete multi-key relation can be a useful substrate, but it is not automatically a mathematical manifold.

Carrier

The transport mechanism between Surfaces. It may change coordinates or representation while carrying declared invariants and provenance.

Preimage

Reverse lookup may produce a set of addresses rather than one unique inverse. Ambiguity is retained instead of manufactured away.

Canonical traversal

RESOLVE → ENCODE → CARRY → DECODE → RECONSTRUCT → COMPARE → TRACE → RETURN_HOME

If reconstruction fails the declared invariants, the result is classified as mutation, semantic decay, or unknown rather than being called a successful semantic rotation.

Semantic rotation

A → Carrier → B → Carrier⁻¹ → A′
compare(A, A′, declared invariants)

A valid rotation is judged against the declared invariant set. Exact bytes are not always required; exact meaning is not assumed merely because bytes round-trip.

Connection to the current S′ models
