## R — What difference matters?

The central distinction is:

```text
interesting structural resemblance
!=
valid mathematical bridge
!=
verified finite computation
!=
proved family-level theorem
!=
proof of the Hodge conjecture.
```

Further non-negotiable distinctions:

```text
same real dimension != same Hodge diamond
same Hodge diamond != same rational Hodge classes
same Hodge numbers != same Picard/Chow structure
symmetry != useful quotient
number of constructed cycles != rank of their cycle classes
projection loss != equality in the source space
calibration family != unresolved target family
retrieval relation != supporting evidence
finite computation != universal proof
```

## P — What should we do next?

### 1. Build a cycle-span deficit instrument

For a declared family of algebraic cycles `Z_1,...,Z_m`, compute

```text
V_known = span_Q([Z_1],...,[Z_m]) ⊂ H_Hodge(X,p).
```

Then compute the current deficit

```text
D = dim H_Hodge(X,p) - dim V_known.
```

A positive deficit means the current cycle generator is incomplete. It is not a counterexample to Hodge.

### 2. Refine the deficit by symmetry sectors

When a certified group action `G` is available, decompose

```text
H_Hodge = ⊕_rho H_rho
V_known = ⊕_rho A_rho
D_rho   = dim(H_rho) - dim(A_rho).
```

Use positive `D_rho` values as targeted cycle-discovery sectors. Do not infer usefulness from symmetry alone.

### 3. Preserve construction sharing

Cycle constructions may reuse ambient classes, exceptional divisors, correspondences, pullbacks, pushforwards, or common components. Count independent cohomology/Chow information, not raw construction-tree size.

### 4. Attack coordinate dependence

Whenever a basis, quotient, primitive decomposition, projection, or elimination is applied, retain the source coordinates and test whether a discarded coordinate still induces a consequential geometric distinction.

### 5. Use calibrated ladders

Run new machinery first on cases where the answer is independently known or bounded:

1. `P^2` and `P^1 x P^1`;
2. abelian surfaces;
3. Kummer K3 surfaces;
4. Fermat quartic K3;
5. smooth cubic fourfolds as a solved calibration for the relevant integral degree-four Hodge classes;
6. only then selected unresolved families/codimensions.

### 6. Apply proof admission

```text
proposal
-> exact definition
-> source check
-> counterprobe
-> exact verifier / computation
-> independent invariant
-> family-level argument
-> barrier / hypothesis audit
-> proof audit
-> only then claim promotion
```

## O — What happened?

### Current supported footholds

- K3 provides a genuine complex-geometric object of real dimension four with Hodge diamond `(1; 0,0; 1,20,1; 0,0; 1)` and Betti numbers `(1,0,22,0,1)`.
- The Kummer construction supplies a concrete bridge from an abelian surface to K3 via quotient and resolution, with sixteen exceptional curves entering the geometry.
- The Fermat quartic supplies an explicit cycle-rich calibration: 48 constructed lines collapse to a rank-20 rational intersection span rather than 48 independent classes.
- Smooth cubic fourfolds remain calibration objects, not open instances to be relabeled as unresolved.
- The 24-cell / quaternion / D4 / E6 material supplies structured symmetry and representation-theoretic search partitions, not Hodge evidence by resemblance alone.
- The P-vs-NP program contributes useful research machinery: range avoidance, symmetry-promise checking, sharing-aware complexity, coordinate counterprobes, and strict proof admission.

### Preserved negative lessons

- A Hodge diamond alone does not identify the rational Hodge lattice or algebraic-cycle span.
- Large symmetry does not automatically create a computationally useful quotient.
- More candidate cycles do not imply a larger independent span.
- A successful finite rank computation does not become a theorem about a family without the required uniform argument.
- A visually compelling 4D construction does not establish a physical extra dimension or an algebraic-geometric equivalence.

- same Hodge diamond / different Picard rank;
