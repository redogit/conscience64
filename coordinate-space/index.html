Coordinate Space Workbench

Public edition · Exact UTF-8 / Float64 transport · September 13, 2026

Encode your own text into ordered numeric coordinates, then recover the exact bytes. Processing stays in this page: no uploads, analytics, accounts or automatic saving. This public edition does not include the private research corpus or historical archives.

1. Encode your text

Browser limit: 1 MiB of UTF-8. Newlines are those supplied by the browser text field. Imported envelopes preserve their bytes exactly.

2. Inspect or import coordinates

Six source bytes per exact 48-bit integer, held in a Float64 number. Length, padding and SHA-256 travel with the ordered array.

3. Verified recovery

Enter text and select Encode and verify.



What this establishes—and what it does not
A successful round-trip verifies bytes under this codec. A digest is not a digital signature, a proof of truth, encryption, or independent evidence. One Float64 does not store an arbitrary document: the ordered sequence and its metadata carry the document. This is encoding, not compression.
The Python source also supplies the typed corpus reader and the validated 64-slot symbol builder, including variable-count layer stacks. Public tests use authored examples, not private records. See the release contract and running instructions.
Missing or changed source dependencies remain unresolved. Local browser processing does not prevent other software, extensions, or another person using the device from seeing entered text. Accessibility smoke tests are not JAWS, NVDA, or conformance certification.
