NEON//VEIL · Public Release

A first-person cyber-fantasy world that keeps its own time. Choose the ZIP for the system that will run or connect to the world.

WindowsSolo/LAN host · Python 3.10+ · START_NEON_VEIL.bat LinuxSolo/LAN host · Python 3.10+ · sh START_LINUX.sh macOSSolo/LAN host · Python 3.10+ · START_NEON_VEIL.command Android / TermuxSolo/LAN host · pkg install python · sh START_ANDROID.sh iPhone / iPadClient helper · another trusted device hosts the world

Solo in four steps

  1. Download the ZIP for your system and extract it completely.
  2. Open README_FIRST.txt and install Python 3.10+ if required.
  3. Run the launcher named on the card above.
  4. Keep the server window open and play in the browser it opens.

Play together on a trusted LAN

  1. One Windows, Linux, macOS, or Android/Termux device starts NEON//VEIL with LAN mode enabled as described in its package.
  2. Keep that host running and use the private address it prints.
  3. On another device, open the NEON//VEIL connection helper and enter that exact address.

Do not port-forward the development server to the public internet. GitHub Pages distributes the release; it does not run the simulation.
