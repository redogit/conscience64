# NEON//VEIL public release

Central Play page: https://redogit.github.io/conscience64/play/

Release page: https://redogit.github.io/conscience64/play/neon-veil/

GitHub Pages is a static download/connection hub, not the game server. The five downloadable packages are exact system-specific distributions derived from `NEON_VEIL_T05_RECEIPT_SAFETY_CHECKPOINT.zip` (SHA-256 `8d26afb7e271398ee2f01586db034b39e8d4a9357bfc996246245eabb9335517`) and omit development tests, private evidence/history, planning records, and unrelated repository files.

- Windows — local solo or trusted-LAN host; Python 3.10+.
- Linux — local solo or trusted-LAN host; Python 3.10+.
- macOS — local solo or trusted-LAN host; Python 3.10+.
- Android/Termux — local solo or trusted-LAN host; install Python inside Termux and keep the game under Termux private storage.
- iPhone/iPad — client helper only; another trusted device hosts the world.

Every package contains `README_FIRST.txt` with system-specific launch steps.
